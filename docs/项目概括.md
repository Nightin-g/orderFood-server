# 大学食堂订餐系统项目概括

## 1. 项目概述

大学食堂订餐系统是一个专为高校食堂设计的在线订餐平台，旨在为学生和教职工提供便捷的订餐服务，同时为食堂店铺提供高效的订单管理和运营工具。

## 2. 技术栈

- **后端框架**：Spring Boot 2.7.x
- **数据库**：MySQL 8.0
- **缓存**：Redis
- **认证**：JWT (JSON Web Token)
- **安全框架**：Spring Security
- **持久层框架**：MyBatis
- **前端**：待定（可集成Vue、React等前端框架）

## 3. 核心功能模块

### 3.1 用户模块
- 用户注册、登录
- 用户信息修改
- 密码修改（带验证码验证）

### 3.2 店铺模块
- 店铺注册、登录
- 店铺信息修改
- 店铺状态管理（营业、休息、暂时歇业、永久停业）
- 菜品管理（添加菜品）

### 3.3 订单模块
- 创建订单
- 查询订单（用户端、店铺端）
- 订单状态管理（取消、支付、接单、拒绝、出餐、配送、取餐、评价、退款）

### 3.4 评论模块
- 创建评论（对店铺或菜品）
- 查询评论（店铺评论、菜品评论、用户评论）
- 删除评论
- 获取平均评分（店铺、菜品）

### 3.5 管理员模块
- 审核店铺
- 审核菜品

### 3.6 验证码模块
- 生成图形验证码
- 验证验证码

## 4. 系统架构

### 4.1 分层架构
- **控制器层**：处理HTTP请求，调用服务层方法
- **服务层**：实现业务逻辑，调用数据访问层方法
- **数据访问层**：与数据库交互，执行CRUD操作
- **模型层**：定义数据模型
- **DTO层**：定义数据传输对象
- **工具层**：提供通用工具方法

### 4.2 安全架构
- 使用JWT进行身份认证
- 使用Spring Security进行权限控制
- 密码加密存储（BCrypt）
- 验证码防止机器人攻击

### 4.3 缓存架构
- 使用Redis存储验证码和JWT令牌
- 使用本地缓存存储评分数据，定时更新到数据库

## 6. 项目特点

1. **安全性**：使用JWT认证、Spring Security权限控制、密码加密存储、验证码防止机器人攻击
2. **可靠性**：分布式锁防止并发操作、事务管理确保数据一致性
3. **性能优化**：缓存机制减少数据库操作、批量更新提高性能
4. **可扩展性**：分层架构、模块化设计、接口标准化
5. **用户体验**：完整的订单流程、实时状态更新、评论评分系统
6. **管理便捷**：管理员审核系统、店铺状态管理、订单管理

## 8. 部署说明

1. **环境要求**：
   - JDK 1.8+
   - MySQL 8.0+
   - Redis 6.0+
   - Maven 3.6+

2. **配置修改**：
   - 修改`application.yml`中的数据库连接信息
   - 修改Redis连接信息
   - 修改文件上传路径

3. **部署步骤**：
   - 执行`mvn clean package`打包项目
   - 执行`java -jar target/OrderFood-0.0.1-SNAPSHOT.jar`启动项目
   - 访问`http://localhost:8082`

## 8. 总结

大学食堂订餐系统是一个功能完整、安全可靠、性能优化的在线订餐平台，为高校食堂提供了一套完整的数字化解决方案。系统支持用户在线订餐、店铺管理订单、管理员审核等核心功能，同时通过缓存机制和分布式锁等技术手段确保系统的性能和可靠性。
